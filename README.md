# 專案進度與文件管理（EPC Project Hub）

太陽光電／儲能 EPC 工程的專案管理系統，單一 HTML 檔，不需安裝、不需後端。

## 功能

- **專案總表** — 進度條、偏差、預期完工、多條件篩選
- **進度排程** — 81 項 EPC 標準 WBS，支援 `FS/SS/FF/SF` 前置任務語法自動排程、浮時與要徑
- **權重制進度** — 依任務權重逐層彙總；每項可選「比例法」或「開工法」
- **三軌日期** — 預定（baseline）／實際／預期完成，並計算進度偏差
- **S 曲線** — 預定 vs 實際累積進度
- **甘特圖** — 預定基準線與實際區間雙軌顯示，日／週／月縮放
- **文件管理** — 1000～6000 標準資料夾、流程狀態、可掛到 WBS 任務、記錄雲端硬碟連結
- **表單模組** — 24 個範本（施工日誌、進料檢驗 ×8、自主檢查 ×12、簽呈等），手機可直接填寫，支援列印／存 PDF
- **進度日誌** — 每項任務的時間軸紀錄

## 使用方式

開啟網址即可使用。資料存在瀏覽器的 localStorage，請用左下角「資料 → 匯出 JSON」定期備份。

> 目前為單機版：每台電腦、每個瀏覽器的資料各自獨立，不會互相同步。

## 示範資料

內建的專案、人名、客戶與案場皆為**虛構示範資料**，僅供展示介面與計算邏輯。

## 自訂

- **表單範本**：表單頁 → ⚙ 表單範本，欄位與檢查項目為純文字編輯，可改成公司實際版本
- **任務權重**：進度排程 → 切「完整欄位」→ 點任務編輯
